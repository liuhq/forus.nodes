# 测试与发布方案

## 内容与规则测试

- 校验 7 个日期、阶段顺序、YAML 结构、中英文对齐和稳定 ID。
- 验证每日阶段可自由互动或跳过，点击“查看最新”后正确刷新帖子。
- 验证每日最后阶段只进行一次剧情总结和资源结算。
- 验证线索、证物、0–3 置信度和隐藏数值效果。
- 验证私信不会在开局显示，且必须由公开互动触发并在下一阶段出现。
- 验证目标人物与 `Forus社区管理员` 是唯一私信对象。
- 验证私信只能回复，不能主动发起，也不能转化为公开证物。
- 验证第 3、5、6 日的隐藏分支优先级。

## 结局验收

1. 目标安全值足够，达到 `target_rescued`。
2. 事实置信度和平台治理值足够，达到 `harassment_stopped`。
3. 目标安全值不足且事实无法确认，达到 `target_died`。
4. 玩家暴露值达到阈值，达到 `player_targeted`。

## 内容安全

- 目标人物明确为 17 岁高中女生。
- 不描写死亡方式、具体自伤方式或血腥细节。
- 不把网络暴力合理化为对错误行为的正当惩罚。
- 不发布可重新扩散个人隐私的具体操作指南。

## 发布门槛

类型检查、内容校验、引用检查、阶段推进测试、私信触发测试、四结局路径测试、键盘操作和移动端阅读测试必须通过。
