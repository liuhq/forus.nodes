# 测试与发布方案

## 测试层级

### 内容校验

- YAML 可解析且符合统一 schema。
- 同章 `zh-CN` 与 `en-US` 的实体 ID、顺序、条件、效果和出口一致。
- 所有账号、卡牌、线索、帖子、遭遇和结局引用存在。
- 每个互动时段引用的选项组存在；`main` 选项成本为 1，`flavor` 选项成本为 0 且没有剧情效果。
- 中英文的互动额度、是否显示额度、提前结束规则、选项成本与阶段结束效果一致。
- 6 月故事只有“物归其人”和“无人签收”；11 月故事只有“本人在线”“公共托管”“全员在线”。
- 每个结局至少存在一条可达路径，不存在无出口场景。
- 流窜 AI 不得拥有名称、账号、头像、战斗单位或独立任务。

### 规则单元测试

- 条件组合：全部、任一、否定、数值阈值与当前周目隔离。
- 效果执行：幂等选项、资源边界、线索、帖子显隐、路线和结局写入。
- 互动额度：成功事务才扣除、失败回滚、零互动结束、额度耗尽、提前结束、未用额度不结转和战斗重试免费。
- 阶段结算：空阶段先执行 `on_end_if_empty`，再执行 `on_end`；遭遇完成后才判断出口，重试不重复结束效果。
- 战斗：固定种子、洗牌、抽牌、费用、护盾、状态持续时间和胜负优先级。
- 存档：序列化往返、schema 迁移、损坏数据拒绝和内容版本兼容。

### 组件与集成测试

- 首页版块可见性和 11 月锁定提示。
- 发帖、评论、回复选项生成正确楼层关系。
- 从个人页返回原帖，历史周目标识正确且不影响当前条件。
- 切换语言后，已发布互动保留语义和位置。
- 战斗胜负能生成不同帖子和后续选项。
- 剩余互动次数仅在显示额度的章节出现；已错过选项禁用且不泄露隐藏效果。

### API 测试

- 注册、登录、登出、错误凭据、重复用户名和会话撤销。
- 密码哈希不是明文，Cookie 属性正确，会话令牌轮换。
- 登录限流、Origin 拒绝、超大存档和未知 schema 版本。
- `If-Match` 成功更新、过期修订返回 409、用户间存档隔离。
- 游客存档注册上传和已有云存档冲突选择。

### 端到端场景

1. 游客从综合讨论进入 6 月故事，完成新手教学并达成“物归其人”。
2. 重开 6 月故事，跳过已读内容并达成“无人签收”。
3. 验证 11 月版块由锁定变为开放。
4. 分别完成“本人在线”“公共托管”“全员在线”。
   - 在《异常活跃》的两个阶段分别验证三选二、提前结束和零互动结束。
   - 在《H-5》验证四选二；零证据时最终只显示“全员在线”，单方向证据只开放对应路线，跨方向证据开放两条证据路线。
   - 在《保持在线》验证最终互动最多一次，直接结束等价于选择“全员在线”。
5. 使用两个不同的 6 月结局存档开始 11 月，确认帖子、选项和战斗路径一致。
6. 注册上传、另一浏览器恢复、制造冲突并分别选择本地与云端版本。

## 无障碍与兼容性

- 全流程可仅用键盘完成；焦点顺序与帖子视觉顺序一致。
- 标题层级、地标、状态文本、错误提示和按钮名称可被屏幕阅读器理解。
- 信息不只依赖颜色；正文和交互满足 WCAG AA 对比度目标。
- 尊重减少动态效果、系统字体缩放和浏览器缩放。
- 桌面为完整体验；常见手机宽度可完成阅读、选择和战斗。
- WebGL 关闭、初始化失败或上下文丢失时仍能完成所有结局。

## 性能预算

- 论坛首屏不等待 WebGL 初始化即可阅读和操作。
- 视效包按路由延迟载入；移动端降低像素比、粒子量和后处理。
- 长帖子列表使用分页或窗口化，避免随周目持续增加 DOM。
- 发布前在中档移动设备验证交互响应和内存稳定性。

## 发布门槛

- 构建、类型检查、单元测试、内容校验和端到端主路径全部通过。
- 数据库迁移经过空库与上一版本副本演练。
- README、部署文档、许可证声明、隐私说明和演示账号准备完成。
- 生产环境不包含调试存档、测试密码、源码映射中的敏感配置或完整请求正文日志。
