# 内容制作与本地化流程

## 源文件约定

剧情源文件采用 `docs/scripts/<story>/<chapter>-<lang>.yaml`：

```text
docs/scripts/xunsheng-0623/01-zh-CN.yaml
docs/scripts/xunsheng-0623/01-en-US.yaml
docs/scripts/xunsheng-1105/03-zh-CN.yaml
```

故事与章节稳定 ID 不随显示标题或翻译修改。账号的 `account_id` 同样固定，所有语言显示相同用户名。

## 编写顺序

1. 在中文文件中锁定章节目标、实体 ID、分支、战斗和出口。
2. 运行 schema、引用和可达性校验。
3. 复制结构到英文文件，只翻译标题、正文、选项、提示和战斗文本。
4. 运行语言结构对齐校验，禁止英文文件自行增加或删除剧情节点。
5. 生成前端消费的按故事和语言拆分 JSON。

## 本地化规则

- 专名遵循 `docs/design/stories-world.md` 的命名表。
- Forus、NC 编号、HUMO、H-5 和论坛用户名保持原样。
- 中文文档中的实现术语采用“中文名 (`codingName`)”；玩家可见剧情不强制附带代码名。
- 英文采用自然本地化，不逐字翻译，但不得改变说话者意图、线索强度、选项风险与结果。
- 帖子楼层、时间顺序和选择数量在语言间严格一致。
- 若中文文本改动了事实，必须同步修改英文并重新审核整章。

## 内容校验

构建应在下列情况失败：

- YAML 字段未知、类型错误或稳定 ID 重复。
- 中英文件实体集合、条件、效果或出口不同。
- 引用不存在的账号、线索、遭遇、帖子、章节或结局。
- 剧情效果引用永久档案来改变 11 月主线。
- 气氛帖子携带主线效果。
- `main` 选项的 `interaction_cost` 不是 1，或 `flavor` 选项的成本不是 0。
- 互动时段的额度小于 1、引用当前场景之外的选项组，或关键选项数量不足以支撑设计要求。
- 中英文文件的互动时段参数、选项成本或阶段结束效果不一致。
- 某个结局不可达，或章节存在没有出口的非终止场景。
- 11 月内容读取 `returned_to_owner` 或 `unclaimed` 作为故事条件；唯一允许的前作检查是 `xunsheng_0623` 已完成。

## 文本审校清单

- 用户名拼写与大小写完全一致。
- NCO13、寰宇和 HUMO 的职责没有互换。
- “南厝”被描述为已经拆除的旧地名。
- H-5、聚合单元和静默样本只在 11 月故事出现。
- 流窜 AI 只留下少量、无名称、无定论的技术痕迹。
- 青少年级内容不出现血腥、露骨伤害或现实仇恨煽动。
