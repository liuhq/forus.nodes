# 内容制作与本地化流程

## 文件约定

故事脚本继续使用：

```text
docs/scripts/h5-incident/package.yaml
docs/scripts/h5-incident/day-01-zh-CN.yaml
...
docs/scripts/h5-incident/day-07-en-US.yaml
```

目录路径暂时保持兼容，但内容 ID、标题和正文已全部替换为《11月5日》。

另有便于阅读的中文剧情文件：

```text
docs/design/story-timeline.md
```

## 编写顺序

1. 在剧情时间线文件中锁定事件、阶段、私信和分支。
2. 在中文 YAML 中实现阶段、帖子、互动、证物和隐藏数值效果。
3. 运行引用、阶段顺序、结局可达性和私信触发校验。
4. 复制结构到英文文件，只翻译玩家可见文本。
5. 运行中英结构对齐。

## 校验规则

- 每个日期至少有一个阶段。
- 阶段序号连续，帖子 ID、互动 ID、私信 ID 和证物 ID 不重复。
- 所有阶段均可通过“查看最新”推进。
- 私信必须有触发条件，不能在首日无条件出现。
- 私信只能由 `reply_direct_message` 互动回复。
- 私信不能作为公开证物或提升公开事实置信度。
- 所有四个结局均存在可达路径。
- 中英文文件的阶段、帖子、互动、私信和效果结构一致。
