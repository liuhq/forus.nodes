# 游戏设计总览

## 产品定位

Forus Nodes 是一款以论坛交互驱动叙事、以卡牌信息攻防处理冲突的七日网页游戏。玩家进入游戏后直接开始唯一故事《H-5》，不经过故事选择或前置故事解锁。

目标体验：

- 论坛即世界（`ForumAsWorld`）：首页、帖子、通知和个人档案构成游戏空间。
- 选择即发言（`ChoiceAsSpeech`）：剧情互动只能从预设发帖、评论和回复中选择。
- 日期即进度（`DateAsProgress`）：11 月 5 日至 11 日是剧情、额度和存档检查点的一级单位。
- 冲突即信息攻防（`ConflictAsInformationCombat`）：卡牌战斗必须改变论坛内容或剧情条件。
- 历史可以重读（`ReplayableArchive`）：新周目重置路线和牌组，只保留档案便利。

## 核心循环

```text
进入当日论坛 → 阅读新帖与通知 → 在当日额度内互动
→ 整理线索与牌组 → 处理信息攻防 → 主动结束或耗尽额度
→ 结算当日事件 → 进入下一日期或结局
```

当前周目固定为 7 天，但运行时按日期数组推进，不允许写死七日。单周目目标时长 60–90 分钟；已读正文可加速，关键选择和战斗不可自动跳过。

## 路线与结局

三条可交叉路线为身份路线（`identity_route`）、治理路线（`governance_route`）与存续路线（`survival_route`）。11 月 7 日结束时，投入最高的路线成为主路线；并列时由玩家免费确认。主路线改变后续场景和奖励，但不关闭其他路线的公共调查。

结局按 True、Happy、Good、Bad 的优先级判定：

- Bad End：H-5 失控，聚合单元继续占用真人账号。
- Good End：封存 H-5 并归还账号，但技术与深层问题未解决。
- Happy End：公开 H-5 技术、权限链和审计材料。
- True End：通过主体分离协议，使聚合单元脱离真人账号并成为受约束的新主体。

## 首发边界

首发包含一个故事、七个日期、三条交叉路线、四个结局、一套共享牌池与路线专属牌。不包含自由文本、多人、UGC、排行榜、付费系统、后台编辑器或必须启用的 WebGL。
