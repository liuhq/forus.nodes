# 《11月5日》游戏设计总览

## 产品定位

《11月5日》（`November 5`）是一款以 Forus 论坛为界面的七日分支叙事游戏。玩家扮演普通旁观者，面对一名 17 岁高中女生遭受的网络暴力，在公开互动、阶段推进、私信回复和证据判断之间作出选择。

核心体验：

- 论坛即世界：帖子、评论、反应、通知和私信构成全部叙事空间。
- 选择即发言：玩家只能使用预设的发帖、评论、回复、赞同和反对文本。
- 阶段即进度：每天由剧情刷新不定数量的帖子，玩家点击“查看最新”手动推进阶段。
- 责任有边界：目标人物确实曾错误公开指控同学，但错误不等于网络私刑的正当性。
- 结果会提前形成：隐藏数值在第 3、5、6 日改变剧情分支，第 7 日只收束既有结果。

## 核心循环

```text
进入当天阶段 → 阅读 Forus 帖子与私信
→ 自由进行预设互动或跳过
→ 点击“查看最新”刷新下一阶段
→ 当天最后阶段结束
→ 展示剧情总结、线索与证物结算
→ 保存并进入下一日
```

不设置每日互动次数限制，不设置卡牌战斗、遭遇战、抽牌、伤害或敌方行动。

## 故事与结局

目标人物参加校园创作比赛，误以为同学盗用朋友作品，在 Forus 公开指控。她随后发现判断错误，删除原帖并私下承认，但没有及时公开澄清。真实私聊被裁剪后传播，营销账号和普通用户继续放大指控，目标人物的照片、学校信息和账号遭到扩散。

四个结局由隐藏数值决定：

- `target_rescued`：被网暴者获救。
- `harassment_stopped`：网络暴力行为被制止。
- `target_died`：被网暴者死亡。
- `player_targeted`：玩家遭受网络暴力。

## 隐藏数值

- `target_safety`：目标人物获得支持、隐私保护和现实援助的程度。
- `truth_confidence`：公开事实材料的可信度。
- `platform_governance`：Forus 的治理介入力度。
- `player_exposure`：玩家公开介入后暴露自身的程度。

隐藏数值不显示为数值条。证物拥有可见的 0–3 置信度，用于解锁选项。

## 阶段与私信

每个 `StoryDay` 持有剧情驱动的 `StoryPhase[]`。玩家可以阅读当前阶段全部帖子，互动或跳过，然后点击“查看最新”。

私信区始终存在，但未触发的私信线程完全不显示。目标人物和 `Forus社区管理员` 只能在玩家完成特定公开互动后，于下一阶段出现在私信区。私信以对话框展示，只能选择预设回复，内容严格不可外传。

## 首发边界

包含一个故事、七日内容、阶段刷新、预设论坛互动、触发式私信、线索、证物置信度、隐藏数值和四个结局。不包含自由文本、多人、UGC、卡牌战斗、对战、排行榜、付费系统或必须启用的 WebGL。
