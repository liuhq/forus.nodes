# 论坛与叙事交互

## 信息架构

### 首页（`ForumHome`）

首页按以下顺序展示：站点导航、当前身份、通知摘要、版块列表、最新帖子与在线状态。三个首发版块为：

- 综合讨论（`general_discussion`）：本地日常、外城消息和非主线气氛帖。
- 浔声小报（6月23日）（`xunsheng_0623`）：初始开放的两章故事。
- 浔声小报（11月5日）（`xunsheng_1105`）：始终可见；完成第一期任意结局后开放。

锁定版块可以查看简介和开放条件，不能查看内部帖子。解锁通过站内通知和版块状态变化同时反馈。

### 帖子详情（`ThreadView`）

帖子由首帖（`Post`）、评论（`Comment`）和回复（`Reply`）组成。回复必须引用目标评论或回复，数据保存父级 ID，视觉上最多展示两层缩进，超过层级以引用条显示，避免移动端过窄。

编辑、删除、隐藏、锁定和置顶都是剧情状态，不真正丢弃内容。被删除内容根据玩家线索显示“已删除”、残留摘要或恢复全文。

### 个人页（`UserProfile`）

个人页保留论坛外观并从顶部导航、头像或用户名进入。标签页包括：

- 动态（`activity`）：当前周目发帖、评论与回复。
- 调查（`investigation`）：当前线索、立场与路线提示。
- 档案（`archive`）：历史周目、已见帖子和结局。
- 牌册（`compendium`）：已发现卡牌，不直接加入当前牌组。
- 存档（`save`）：本地/云端摘要、同步和冲突选择。
- 设置（`settings`）：语言、文字、声音和视效质量。

历史互动可返回原帖，但明确标注“档案记录”，其效果不在当前周目执行。

## 选项式互动

交互选项（`InteractionChoice`）包含：

- 动作种类（`action_type`）：`create_post`、`create_comment`、`create_reply`。
- 目标（`target_id`）：版块、帖子或具体楼层。
- 标题（`title`）：只用于发帖。
- 正文（`body`）。
- 语气标签（`tone`）：调查、支持、质疑、谨慎、公开或撤回。
- 前置条件（`conditions`）与执行效果（`effects`）。
- 一次性标记（`once`），剧情选项默认只能执行一次。

玩家点击选项后先显示发布预览，再确认提交。预览展示最终文字和公开语气，不展示好感、路线点数等隐藏结果。发布后不得编辑或撤回；只有重开整篇故事才能改选。

## 互动时段

互动时段（`InteractionStage`）把同一段论坛时间内的关键发言组织在一起。阅读帖子、切换页面、查看个人页、整理牌组和战斗均不消耗次数；叙事作用域为 `main` 的发帖、评论和回复固定消耗 1 次，`flavor` 互动固定消耗 0 次。

- 玩家可以在次数耗尽前结束阶段，甚至零互动结束；未使用次数作废且不结转，也不提供防护或其他补偿。
- 结束阶段前显示不可撤回提示。阶段结束后，未选关键互动保留为禁用的“已错过”记录，不显示其效果。
- 成功写入论坛内容并提交整组选项效果后才扣除次数；任何写入或效果失败都必须回滚。
- 战斗由关键互动或阶段结束触发时只扣除最初的论坛互动；先完成战斗结算再判断场景出口。战斗重试免费，也不重复发布或执行阶段结束效果。
- 场景出口只在互动阶段结束后判断，避免第一次发言提前跳走而浪费剩余额度。

6月《错投》隐藏额度，以每阶段最多1次互动完成教学；《签收》开始显示“本阶段还可进行 N 次互动”。11月《异常活跃》的两个阶段均为三选二，《H-5》为四选二，《保持在线》只有一次最终互动。

路线可用性不直接提示：没有满足条件的最终发言不会显示。H-5证据阶段零互动时只剩“全员在线”；取得任一本人方向证据后显示“本人在线”，取得任一托管方向证据后显示“公共托管”。

## 剧情状态

状态分四层：

- 永久档案（`permanent_archive`）：已见内容、图鉴、结局和辅助跳读。
- 故事周目（`story_run`）：当前故事路线、资源和章节。
- 章节状态（`chapter_state`）：帖子显隐、线索、战斗与局部标记。
- 界面状态（`ui_state`）：当前路由、滚动位置、草稿预览，不参与剧情判断。

条件只允许显式读取声明过的层级。11 月故事的访问条件可读“6 月故事已完成”；进入后不得读取 6 月结局或路线变量。

## 节奏与失败

- 普通选项不会立即导致坏结局，而是改变证据、牌组或最终战难度。
- 战斗失败首先生成对应的论坛后果，并允许从本章开始处重试。若场景出口回到同一场景，运行时直接提供“再次整理证据”操作并重启已经触发的遭遇，不要求再次执行标记为一次性的论坛选项。
- 连续两次失败后开放辅助选项：展示敌方意图说明或提供一张临时防护牌，不降低结局要求。
- 核心战失败可以导向坏结局，但必须在战前明确提示“该发布将决定本期结果”。

## 气氛内容

综合讨论复用六个普通账号，展现天气、饮食、维修、NC5 与 NC10 传闻。气氛选项的叙事作用域为 `flavor`，效果必须为空；它们可以进入个人页历史，但不改变资源、路线或结局。
