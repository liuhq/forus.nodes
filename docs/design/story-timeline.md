# 《11月5日》完整剧情时间线

## 故事核心

17 岁高中女生 `@晚自习后` 参加校园创作比赛。她看到一组不完整的作品对比图，误以为同学盗用了朋友的设计，于是在 Forus 公开指控对方。

她后来发现自己判断错误，删除原帖并私下承认，但没有及时公开澄清。被指控同学的朋友发布真实但被裁剪的私聊截图，营销账号和普通用户继续扩散，目标人物的照片、学校信息和账号遭到围攻。

她确实做错过事，但她的错误不等于任何人都有权对她实施网络私刑。

## 隐藏数值

- `target_safety`：目标人物的安全、信任和现实支持。
- `truth_confidence`：公开事实材料的可信度。
- `platform_governance`：Forus 的治理介入程度。
- `player_exposure`：玩家账号暴露和被检索的程度。

证物置信度为 0–3，可见；隐藏数值不显示。

## 第一天：错误指控出现

### 阶段一：求助帖

Forus 出现帖子《有人说我偷了作品》。目标人物说自己已经删除了原帖，但评论区开始要求她公开学校和比赛信息。

玩家可以：

- 回复“先确认你是否安全，我不会转发你的个人信息。”
- 回复“你应该先把完整证据发出来再解释。”
- 赞同要求停止扩散个人信息的评论。
- 反对将错误指控直接等同于“恶意霸凌”的评论。

尊重隐私的互动设置 `target_notice_pending`，但不会立即产生私信。

### 阶段二：截图开始流传

刷新帖子《她自己都承认了》。`@截屏的人` 发布目标人物私聊的一小段，`@热榜搬运站` 将其改写成“她长期操纵同学排挤别人”。

玩家可保存公开链接、反对继续传播个人信息，或直接引用截图参与争论。公开引用会提高 `player_exposure`。

### 阶段三：第一次私信

如果玩家在阶段一完成尊重隐私的回复，目标人物在下一阶段出现在私信区。她不会自动弹窗，玩家点击私信条目后在对话框中阅读：

> 你是刚才说“先确认我是否安全”的那个人吗？我不知道该不该把事情告诉你。

玩家可回复：

- “你可以先告诉我现在是否安全，不必立即证明自己清白。” → `target_safety +1`
- “把完整截图和草稿发给我，我才能帮你。” → `target_safety -1`
- “我不会把你的私信转发出去。” → 设置 `private_boundary_respected`

### 当日总结

玩家获得线索 `cropped_context`：流传截图缺少上下文。尊重隐私的玩家获得证物 `public_post_timeline`，置信度 1。

## 第二天：删除不等于澄清

### 阶段一：删除记录

帖子显示目标人物删除了原指控，但删除时间被解释为“心虚”。玩家可查看公开缓存、比较时间戳，或加入“她删帖就是默认有罪”的讨论。

### 阶段二：版本记录

`@原稿保存者` 发布一个公开草稿链接，但仍缺少授权说明。玩家可以请求完整版本、赞同核对时间线，或反对继续传播未核实结论。

获得证物 `draft_version`，初始置信度 1。

### 阶段三：目标人物私信

如果 `private_boundary_respected` 存在，目标人物来信：

> 我确实以为她偷了作品。我当时没有查清楚就发了帖子。后来我私下道歉了，但我不敢公开说，因为我怕他们会把道歉也当成新的证据。

玩家可接受其承担责任、要求她准备公开说明，或继续逼问更多私密细节。私信内容不能提升 `truth_confidence`。

### 当日总结

玩家获得线索 `target_admitted_error`。核对公开草稿可将 `draft_version` 提升至置信度 2。

## 第三天：完整语境或沉默

### 阶段一：两份草稿

公开帖子出现两个版本的创作草稿。一个版本显示两名学生曾交换设计意见，另一个版本被截去了日期和署名。

如果 `truth_confidence >= 2`，玩家可解锁“对照完整版本”选项，获得线索 `shared_draft_history`。

### 阶段二：责任边界

玩家可以发表：

- “她需要为错误指控道歉，但这不等于可以公开她的学校和照片。” → `truth_confidence +1`、`target_safety +1`
- “既然她错过，就应该接受所有后果。” → `target_safety -1`、`player_exposure +1`
- “先确认原始材料，再讨论责任。” → `truth_confidence +1`

### 阶段三：分支

- `target_safety >= 2`：目标人物私信提供完整时间线，并说明不希望公开的内容。
- 否则：她停止回复，只留下未发送的道歉草稿。

## 第四天：公开证据与私人边界

### 阶段一：授权记录

`@比赛观察员` 发布比赛规则和部分授权记录。玩家可整理公开时间线、赞同暂缓扩散，或把目标人物的私聊内容暗示到公开讨论中。私信不可外传，因此后者只会造成信任和安全损失。

### 阶段二：Forus 举报入口

玩家可以举报集中辱骂、请求隐藏个人资料，或提交公开帖子链接。完成保护互动设置 `forus_safety_review_pending`，但管理员不会当场私信。

### 阶段三：官方通知

Forus 公告提示“正在核查集中举报”，但未公布处理结果。玩家可选择继续公开核对证据，或用自己的账号替目标人物争论。

## 第五天：平台是否介入

### 阶段一：热榜搬运

`@热榜搬运站` 发布汇总帖，标题将“错误指控”改写成“惯犯证据”。评论数量迅速增加。

### 阶段二：Forus社区管理员私信

只有玩家此前完成举报或账号保护互动时，`Forus社区管理员` 才会出现在私信区：

> 你好，这里是 Forus社区管理员。相关帖子已进入审核队列。我们看到目标账号正在遭遇集中回复和个人信息扩散。你可以提交公开链接，但请不要转发任何私信内容。

玩家可回复：

- “请先限制集中回复并隐藏个人资料。” → `platform_governance +1`、`target_safety +1`
- “我会整理公开时间线，不提交私信。” → `platform_governance +1`
- “我把她的私信也一起发给你们。” → 该选项不显示；私信严格不可外传。

### 阶段三：主要分支

- `truth_confidence >= 4 && platform_governance >= 2`：Forus 开启正式复核。
- `target_safety <= 1`：目标人物进入停止上线和现实支持危机。
- `player_exposure >= 3`：玩家的历史发言开始被集中检索。

## 第六天：不可逆方向

### 救助分支

当 `target_safety >= 4` 且 `player_exposure < 4`，目标人物私信确认已联系可信成年人或现实支持人员。玩家进入 `target_rescue_path`。

### 制止分支

当 `truth_confidence >= 4` 且 `platform_governance >= 3`，Forus社区管理员私信确认正式复核、限流和个人资料保护已经启动。玩家进入 `harassment_stop_path`。

### 危机分支

当 `target_safety <= 1 && truth_confidence < 4`，目标人物停止回复，公开账号进入停用状态。玩家进入 `target_danger_path`。

### 玩家暴露分支

当 `player_exposure >= 4`，Forus社区管理员提醒玩家的账号开始被检索，玩家进入 `player_targeted_path`。

## 第七天：结果收束

### `target_rescue_path`

目标人物暂时离开公开争议，现实支持网络接手安全安排。Forus 删除违规内容并保护账号，但公开事实仍需要后续修复。

结局：`target_rescued`，被网暴者获救。

### `harassment_stop_path`

Forus 发布复核结果，确认流传截图缺少上下文，限制继续扩散，并对个人信息传播进行处理。目标人物仍需为错误指控道歉，但网络暴力行为被制止。

结局：`harassment_stopped`，网络暴力行为被制止。

### `target_danger_path`

后续通知确认目标人物在持续围攻中死亡。文本只描述结果，不描述死亡方式或过程。玩家回看此前被跳过的求助与保护节点。

结局：`target_died`，被网暴者死亡。

### `player_targeted_path`

玩家的账号被集中转发，旧发言被断章取义，私信区出现大量骚扰请求。Forus社区管理员建议玩家暂时关闭公开资料并保存举报记录，但玩家已经成为新的网暴对象。

结局：`player_targeted`，玩家遭受网络暴力。
