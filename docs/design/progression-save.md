# 周目、阶段、私信与存档

## 单故事周目

故事周目对应 `online_harassment_case`，显示名称为《11月5日》。首次进入直接创建周目，完成后可从档案开始新周目。

周目保存当前日期、当前阶段、已完成阶段、帖子状态、线索、证物置信度、隐藏数值、私信状态、私密旗标、阶段分支和结局。

## 保存时机

以下操作完成后保存：

- 公开互动提交。
- 私信回复提交。
- 点击“查看最新”并完成阶段结算。
- 每日总结与资源结算。
- 结局写入。

阶段结算必须是原子操作，包含阶段锁定、隐藏数值变化、线索/证物结算和下一阶段刷新。

## 私信保存

私信线程只保存已触发的线程。未满足条件的私信不写入玩家可见状态。消息状态为 `unread`、`read`、`replied` 或 `expired`。

## 版本迁移

故事内容版本升级为 `3.0.0`。旧故事内容没有可迁移的运行时存档；旧故事存档应标记为不兼容，不得继续影响新故事的隐藏数值或结局。
