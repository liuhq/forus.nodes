# 界面、阶段与私信

## 页面布局

- 首页：Forus 公告、当前日期、当前阶段、最新帖子和阶段推进按钮。
- 版块页：当前阶段的全部帖子和预设互动。
- 帖子详情：首帖、评论、回复、赞同、反对和线索标记。
- 私信区：已触发的私信线程列表、未读标记和对话框。
- 个人页：动态、调查、线索、证物、存档和设置。

## 阶段推进

“查看最新”是当天阶段推进按钮。点击后锁定当前阶段互动，刷新下一批帖子，并在每日最后阶段结束时打开剧情总结。

不因未读帖子强制阻塞，不自动弹出下一阶段内容。

## 私信对话框

私信入口始终位于 Forus 导航中，但只有满足触发条件的线程才出现在列表里。点击条目打开对话框：

- 消息以对话气泡按时间排列。
- 回复选项固定在对话框底部。
- 无自由文本输入。
- 关闭后返回原私信条目。
- 不自动抢占焦点，不强制打开。

对话框支持键盘操作、Esc 关闭、焦点返回和 live region 新消息提示。

## 视觉原则

Forus 使用纸白、灰蓝和低饱和青色。网络暴力通过重复转发提示、评论数量变化、通知堆积和隐私警告表达，不使用血腥或惊悚视觉。

不依赖 WebGL。所有关键文字、数值和私信内容保留可访问 DOM 版本。
