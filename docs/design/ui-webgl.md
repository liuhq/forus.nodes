# 界面、视觉与可选视效

## 视觉原则

界面模拟长期运行的真实社区：紧凑排版、清晰楼层、克制状态色，不使用图片素材。头像由用户名首字、CSS 图案和稳定色生成。桌面为主内容加侧栏，移动端为单列。

日期、当日剩余互动次数和主路线提示应融入论坛导航与通知，不使用脱离论坛语境的传统游戏 HUD。Happy 与 True 的隐藏选项在未解锁时不显示占位。

## 页面布局

- 首页：站点公告、当前日期、版块、最新帖子、连接摘要。
- 版块页：简介、分页帖子和可用发帖选项。
- 帖子页：首帖、楼层树、线索标记和互动选项。
- 战斗页：桌面在帖子旁展开，移动端使用可返回的全屏路由。
- 个人页：动态、调查、档案、牌册、存档和设置。

## 基础视觉

纸白、灰蓝和低饱和青构成正常论坛。H-5 异常通过 CSS 重复光标、轻微错位、边框重影和文字状态提示表达。关键文字始终只保留一个可访问 DOM 版本，不通过视觉层删除或替换。

卡牌反馈同时使用轮廓、位置、数值与 live region。稳定度、防护和影响力具有独立文字标签与图标，不能只靠颜色区分。

## 视效适配器

无操作适配器（`NoopEffectsAdapter`）是默认且完整支持的实现。可选 WebGL 适配器（`WebGLEffectsAdapter`）只能在论坛 DOM 后方或非关键覆盖层渲染，不接管文字、焦点、滚动和命中测试。

视效质量（`EffectQuality`）支持 `high`、`balanced`、`low`、`off`。WebGL 包不存在、加载失败或上下文丢失时切换到 `off`，不显示阻断错误。`prefers-reduced-motion` 默认使用 `off`。

## 无障碍

- 使用语义标题、文章、列表、引用、时间和按钮。
- 新楼层、战斗伤害、数值变化和日期推进通过节制的 live region 播报。
- 全流程支持键盘；卡牌详情和关键词解释可固定展开。
- 官方、组织和普通账号同时使用文字标签与样式区分。
- 动画期间保持按钮可用，或明确标记短暂结算状态。
