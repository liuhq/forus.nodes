# 界面、视觉与 WebGL

## 视觉原则

界面模拟长期运行的真实社区站点：紧凑排版、清晰楼层、可辨认的版主/官方标记和克制的状态色。不得使用角色插画、背景图片或图像头像；头像由用户名首字、CSS 图案和稳定色值生成。

桌面采用主内容加右侧栏布局，移动端合并为单列。核心正文最大阅读宽度受限，超宽屏把空间留给站点背景和非交互 WebGL，不拉长文本行。

## 页面布局

- 顶部导航：Forus 品牌、首页、版块、个人页、通知、语言和账号菜单。
- 首页：站点公告、版块卡片、最新帖子、城市连接摘要。
- 版块页：版块说明、分页帖子列表、锁定/完成状态和发帖选项入口。
- 帖子页：首帖、楼层树、证据标记、互动选项和相关帖子。
- 战斗层：仍保留帖子上下文；桌面在正文旁展开，移动端进入可返回的全屏路由。
- 个人页：沿用论坛用户资料视觉，不使用独立游戏 HUD。

## 城市与故事视觉

### 通用论坛

纸白、灰蓝和低饱和青色构成正常状态。程序化噪点、扫描线和连接节点仅作低对比背景，不影响正文对比度。

### 6月23日

使用偏暖纸张、褪色打印边缘、物流标签线框和缓慢移动的地址网格。无主件出现时只用 CSS 票据和文字编号，不绘制包裹图片。

### 11月5日

使用冷色界面、重复光标、账号重影和局部错位。聚合单元复制行为以相同 DOM 内容的短暂 WebGL 残影表现，真实文字始终保持单份可访问版本。

### 死寂侵蚀

死寂数据表现为空间片段化、字符缺失的视觉副本和远景网格坍缩。不得真正删除剧情文字；动画结束后必须恢复稳定可读状态。

## 动效规则

- 页面切换 180–280ms；关键异常最多 600ms，均可跳过。
- 出牌反馈优先使用位置、轮廓和数字变化，不依赖大面积闪光。
- 同屏粒子和后处理有硬上限，连续低帧率自动下降质量。
- `prefers-reduced-motion` 下禁用抖动、视差、残影和快速缩放。
- 所有动画期间保持按钮可用或明确标记短暂结算状态。

## 无障碍

- 论坛内容使用语义化标题、文章、列表、引用、时间和按钮元素。
- 新评论插入、战斗伤害、状态变化通过节制的 live region 播报。
- 卡牌可通过键盘顺序选择；详情与关键词解释可固定展开。
- 官方账号、编辑和普通用户的区别同时使用文字标签与样式。
- 锁定、成功、危险和路线信息不能只用颜色表达。
