# Forus Nodes

## 游戏内容

Forus Nodes 是一款以拟真论坛为主要界面的文本互动与卡牌 Roguelike 网页游戏。玩家通过预设选项发帖、评论和回复，在论坛页面中调查异常事件、收集线索，并以卡牌化的信息攻防处理冲突和推动剧情。
